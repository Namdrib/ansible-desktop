# Powerline Config Files

This directory contains powerline config files. The directory structure matches
what powerline would expect to read, so the entire directory can be dropped into `~/.config/`

Depending on how powerline is run, after any changes are made, run
`powerline-daemon --replace` to make changes take effect. `tmux` configurations
may also need to be reloaded separately

The gruvbox_dark colors and colorschemes files come from the
https://github.com/PetrusZ/tmux-powerline-gruvbox-colorscheme repo, which is
licensed under the MIT license.
